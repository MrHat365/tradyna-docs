# 测连、编辑与删除

管理已接入账户：验证密钥、轮换密钥、安全删除，以及在 DOM 里选对账户。

## 测试连接

账户列表每一行右侧有 **插头** 图标，悬停标题为「验证 API 配置」。

1. 确认你对该行有管理权限（按钮可点；只读成员点不了）
2. 点击插头
3. 权限列下方会出现结果：
   - **验证成功**：密钥能打通交易所只读/鉴权探测
   - 红色错误原文：密钥错、Passphrase 错、IP 白名单、权限不足、所侧限流等

测连是**显式、限频**的动作，不是后台一直轮询。失败时先对照交易所后台：Key 是否启用、权限是否含合约、白名单是否包含终端出口 IP、Passphrase 是否抄对。

::: tip
新建或刚轮换密钥后，先测连再开 DOM / 网格，能少踩很多「投影起不来」的坑。
:::

## 编辑账户 / 轮换密钥

点行内 **铅笔**（编辑账户）。

<figure>
  <img src="/screenshots/09-account-edit-dialog.png" alt="编辑交易账户对话框" />
  <figcaption>编辑时：交易所锁定；API 栏留空=不改；已保存 Key 只显示打码。</figcaption>
</figure>

要点：

| 项 | 行为 |
| --- | --- |
| 交易所 | **不能改**（提示：「已接入账户不能修改所属交易所」） |
| 账户名称 / 备注 | 可直接改 |
| API Key / Secret / Passphrase | 占位「留空则不修改」；**全部留空 = 密钥不变** |
| 已保存 Key | 仅打码片段，系统不回显完整 Key |

**轮换密钥推荐顺序：**

1. 交易所后台创建新 API（权限、白名单与旧 Key 对齐）
2. 终端编辑：填入新 Key / Secret（及 Passphrase）→ 保存
3. 测连成功
4. 再回交易所后台**禁用/删除旧 Key**
5. 若该账户正开着 DOM，关掉重开一扇，让私有状态按新凭证重建

只改名称不改密钥时，密钥三栏保持空白即可。

## 删除账户

点行内红色 **垃圾桶**。确认框文案大意：

> 确认删除「某名称」？删除后该账户的凭证、订单意图与策略记录将被移除，此操作不可撤销。

按钮：

| 按钮 | 何时用 |
| --- | --- |
| 取消 | 不删 |
| 确认删除 | 常规删除：系统会先做风险校验 |
| 强制删除 | 仅当普通删除失败、账户已无法恢复时；跳过部分风险验证 |

### 删除前你应先清干净的东西

系统会拦不安全删除，界面可能直接报错（原文以提示为准），例如：

- 还有引用该账户的经典网格 / 高级网格策略 → **先停并删除策略**
- 本地仍有未终结的订单意图 → **先把相关挂单/意图收敛完**
- 交易所侧仍有**持仓或未成交订单** → **先平仓、撤单**
- 删除前账户激活超时、无法验证风险 → 稍后重试；确认账户已废且无风险后，才考虑强制删除

::: danger
强制删除是逃生口，不是日常按钮。有仓有挂单时硬删，终端侧记录没了，交易所仓位还在——对账会变难。
:::

删的是 **Tradyna 里的托管记录**，不会自动作废交易所后台的 API Key。删完后建议去交易所禁用该 Key。

## 维护中

权限列若出现 **维护中**（盾牌提示：维护排空超时，交易已被封锁）：

1. 有权限时点行内 **解除维护**
2. 成功显示「已解除」；失败看红色原文
3. 解除后再测连、再开 DOM

## 在 DOM 里选用账户

账户本身不「自动变成」当前交易上下文。常用路径：

### 路径 A：交易规则页（最常用）

1. 左侧 **交易规则**
2. 顶部选交易所页签（Bitget / WEEX / Gate / Binance USD-M）
3. 右侧下拉 **选择交易账户**（只列出该所下你可用的账户）
4. 在品种行点 **DOM** → 弹出独立 DOM 窗（不是 iframe）

<figure>
  <img src="/screenshots/10-rules-pick-account.png" alt="交易规则页选择账户后开 DOM" />
  <figcaption>交易规则：先选所 → 再选账户 → 品种行「DOM」。未选账户时 DOM 按钮不可用。</figcaption>
</figure>

### 路径 B：策略监控

策略列表上的 **打开 DOM** 会带上该策略绑定的账户与品种。

### DOM 里账户是锁定的

打开后，侧栏账户由「打开时的交易上下文」决定，不是在梯子里随便切换另一套 Key。要换账户：关掉窗口，回规则页换账户再开。

窗口地址形态类似：`/dom?symbol=BTCUSDT&account=……`（账户 ID 在账户列表名称下方的等宽字符串）。

## 角色与按钮灰掉时

| 现象 | 原因 |
| --- | --- |
| 没有「添加账户」 | 只读成员，或会话无创建权限 |
| 插头/铅笔/垃圾桶灰掉 | 你不是该账户凭证管理人（例如看别人的只读行） |
| 列表为空 | 还没人添加，或你看不见别人名下账户 → 找超级管理员添加/转移 |
| 测连一直失败 | 见 [常见问题](/guide/accounts-exchanges#常见问题) |
