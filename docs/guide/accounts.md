# 账户是什么

交易所账户 = 你在 Tradyna 里托管的一套 **API 密钥**，用来连某一家交易所的合约账户。  
开 DOM、下单、跑网格，都要先有可用账户。

::: tip 界面以实装为准
下文配图来自真实终端；按钮文案、列名若有微调，以你当前登录后的界面为准。
:::

## 它管什么、不管什么

| 管 | 不管 |
| --- | --- |
| API Key / Secret（以及部分交易所的 Passphrase） | 交易所网页登录密码 |
| 在终端里的显示名、备注 | 链上提现地址 |
| 测连、编辑密钥、删除托管记录 | 交易所后台里的 API 创建本身（删终端账户 ≠ 自动删交易所 API） |

密钥保存在终端侧，界面**不会**回显完整 Key；编辑时只看到打码片段（如 `bg_1*********`）。

## 谁可以管账户

登录后看左下角角色标记：

| 角色 | 添加账户 | 测连 / 编辑 / 删除密钥 | 用户管理（转移账户） |
| --- | --- | --- | --- |
| 超级管理员 | ✅ | 全部账户 | ✅（仅此角色可见「用户管理」） |
| 管理员 | ✅ | 可管**非**超级管理员名下账户 | ❌ |
| 交易员 | ✅（自己添加的归自己） | 仅**自己名下**账户 | ❌ |
| 只读成员 | ❌（看不到「添加账户」） | ❌（操作按钮不可用） | ❌ |

账户列表「权限」列：

- **可交易**：你能用该账户做交易类操作
- **只读**：能看见，不能当交易账户用

若某行显示 **维护中**，交易会被拦住，有权限的人可点 **解除维护**。

## 怎么进「账户」页

1. 打开终端并登录（成员邮箱密码，或超级管理员用 Owner 访问令牌）→ 见 [登录与界面导览](/guide/login)
2. 左侧导航 **交易 → 账户**
3. 顶栏搜索框也可搜「账户」后回车跳转

## 和「用户管理」的关系

超级管理员可在 **系统 → 用户管理** 里：

- 创建成员（交易员 / 只读 / 管理员）并设初始密码
- 把某个交易账户 **转移** 给另一名活跃用户（原归属方默认访问会被撤销）

终端里**没有**「给成员勾选多个账户只读授权」的单独矩阵；日常就是：**谁创建/被转移到谁名下，谁就能管密钥**；超级管理员可跨成员操作。
