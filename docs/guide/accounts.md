# 账户与权限

这一章站在**使用者**视角：怎么选账户、看余额仓位；管理员只写一小段。

## 选账户

打开 DOM 或多 DOM 前，先选对交易账户。控制台 **账户** 页列出你有权限的账户。

| 你能做什么 | 说明 |
| --- | --- |
| 查看账户 | 名称、交易所、状态 |
| 打开 DOM | 从账户行 / 概览进入 |
| 看余额与仓位 | DOM 侧栏与交易投影；须账户已连通 |

账户连不上时：先点管理员提供的「测试」能力（若你有权限），或直接找管理员。

## 交易规则

**交易规则**页能看到品种的最小量、步进、精度等。规则未同步时，某些品种可能无法正常交易或网格校验失败——联系管理员同步对应交易所规则。

## 余额与仓位

- 余额、仓位、挂单都是**实时投影**，不是你手动刷新网页「查一次 REST」
- 切换账户后等投影就绪再下单
- 「投影中断」→ 暂停操作，等恢复

## 若你是管理员

短节即可：

1. 在 **账户** 页添加交易所 API 凭证，可先「测试」再保存
2. 在 **交易规则** 对目标交易所执行同步（该所最好没有正在用的行情窗，否则可能失败）
3. 在 **用户管理**（仅超级管理员）创建成员、分配角色、授权可交易账户
4. 删除账户前确认没有未了挂单与风险敞口（界面会拦不安全删除）

普通交易员**不需要**自己管这些。

## 权限怎么理解

| 场景 | 常见原因 |
| --- | --- |
| 列表里没有账户 | 未被授权 |
| 能看不能改策略 | 缺策略管理权限 |
| 看不到用户管理 | 不是超级管理员 |

管理员授权的是「哪几个账户你能动」，不是多套独立系统。
