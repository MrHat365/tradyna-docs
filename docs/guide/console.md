# 控制台

除 DOM 独立窗外，日常管理都在控制台（登录后的主站）。

## 你会点到的页

| 页面 | 干什么 |
| --- | --- |
| 系统概览 | 看状态、快捷进 DOM / 其他入口 |
| 账户 | 账户列表；有权限者添加 / 测连 / 编辑 / 删除 → [账户教程](/guide/accounts) |
| 交易规则 | 看品种规则；管理员同步规则 |
| 套利工具 | 辅助工具页（以当前界面为准） |
| 策略监控 | 经典 + 高级网格列表与启停 |
| 用户管理 | 仅超级管理员：成员与授权 |

## 策略监控

<figure>
  <img src="/screenshots/06-console-strategies.png" alt="策略监控页" />
  <figcaption>策略监控：状态、活动单、闸门；可暂停 / 继续 / 停止 / 打开 DOM。</figcaption>
</figure>

典型用法：

1. 过滤到你的账户或品种
2. 看运行态、待核对、闸门原因（高级）
3. 暂停 / 继续 / 停止
4. 终态记录可删除
5. 「打开 DOM」跳回梯子盯盘

::: tip
高级网格请把本页当主控台；DOM 侧栏更适合改参与首次启动。
:::

## 推荐日常流

1. 登录 → 确认账户在线
2. 开 DOM 看行情与手工单
3. 网格：DOM 里保存启动 → 回来策略监控盯盘
4. 收工：策略监控停止；确认入口单已清（TP/SL 可能还在护仓）

## 管理员补充

- 新成员：用户管理创建 → 授账户
- 新交易所凭证：按 [添加教程](/guide/accounts-add) → 测连 → 交易规则同步
- 出问题：先看策略监控状态与 DOM 投影提示，再决定停策略或找运维
