# 常见问题

面向终端用户。按症状找答案。

## 登录

**登不上 / 一直回登录页**  
检查邮箱密码或 Owner 令牌是否正确；令牌是否过期或被轮换。清掉站点 Cookie 后再试。多开隐私窗容易串会话。

**登录后空白或很快掉线**  
换浏览器或关多余标签；联系管理员确认服务是否在线。

## 行情与 DOM

**梯子没深度 / 一直转圈**  
确认品种与交易所选对；等几秒；关掉再开 DOM。仍无行情 → 管理员检查该所行情是否可用。

**提示投影中断**  
账户私有状态不同步。先别当实盘确认，等恢复；可刷新窗口。网格若依赖投影，可能拒新开。

**点了下单没反应**  
检查下单量是否合法（最小量/步进）；账户是否允许交易；是否点在了不可下单的区域。

## 账户

完整步骤见 [账户管理专题](/guide/accounts)（添加 / 测连 / 编辑删除 / 各所字段）。

**看不到账户**  
尚未添加，或账户在别人名下且你不可见。找超级管理员添加或 **转移** 账户。

**没有「添加账户」按钮**  
你是只读成员，或当前会话无创建权限。

**测连失败**  
核对 Key / Secret / Passphrase、合约权限、IP 白名单。对照表：[多交易所字段](/guide/accounts-exchanges)。

**删不掉账户**  
先停策略、撤挂单、平仓。系统会拦「仍有持仓或未成交订单」。勿轻易强制删除。

**余额是 0 或不更新**  
等投影；确认账户测通；看 DOM 是否选错账户。

## 经典网格

**改了参数没生效**  
运行中只读。停干净 → 保存 → 再启动。启动读的是已保存稿。

**暂停后单子还在**  
正常。暂停只停补挂。

**停止后还有 TP/SL**  
正常。停止撤入口单，保留随单止盈止损护仓。

**Gate 保存失败**  
关掉 TP/SL。

**和高级一起开？**  
同一账户+品种不行。

## 高级网格

**DOM 上暂停/停止没反应**  
去 **控制台 → 策略监控**。

**挂了很久还不下单**  
看监控页闸门：常见是预热中、趋势挡住、敞口触顶、风险视图不可用。

**保存后宽度没变**  
不会热更新。先停止，再改保存，再启动。

**空参考标的**  
可以，但界面会要求确认。

## 控制台

**没有用户管理**  
你不是超级管理员。

**策略删不掉**  
只能删已停止等终态。先停止。

## 还是不行

把这些发给管理员即可（不要发密码/API Key）：

1. 大概时间点
2. 账户名（显示名）与品种
3. 界面原文提示（投影中断、闸门文案、错误条）
4. 你刚做的操作（启动网格 / 下单 / 登录）
