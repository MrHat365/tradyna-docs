# 登录与界面导览

## 登录

默认是**成员登录**（邮箱 + 密码）。若你是超级管理员，点「改用 Owner 访问令牌」。

登录成功后进入控制台；会话失效会回到登录页。多标签页会同步登出状态，避免串会话。

## 角色一览

界面上可能看到的身份：

| 角色 | 你会看到什么 |
| --- | --- |
| 交易员 | 被授权账户上的交易、网格控制（视权限） |
| 只读成员 | 可查看，不能改策略/下单（以管理员授权为准） |
| 管理员 | 更多账户与成员管理能力 |
| 超级管理员 | 全部能力，含用户管理页 |

普通交易员只需要关心：**自己能用哪些账户**。

## 主界面结构

登录后常见几块：

| 区域 | 干什么 |
| --- | --- |
| 系统概览 `/` | 健康状态、快捷入口、开 DOM |
| 账户 | 看账户列表；管理员可增删改、测连通 |
| 交易规则 | 看品种步进/精度；同步规则后才能稳妥交易 |
| 策略监控 | 经典 + 高级网格列表，启停盯盘 |
| 用户管理 | **仅超级管理员**可见 |

## 从控制台进 DOM

1. 选好交易账户
2. 选品种（如 `BTCUSDT`）
3. 点 **DOM** —— 会弹出独立窗口（不是嵌在页面里的小框）

多品种可同时开多扇 DOM 窗，各自独立。

## 权限直觉

- 看不到某个账户 → 没被授权，找管理员
- 能看策略但不能启停 → 缺「管理策略」类权限
- 用户管理入口没有 → 你不是超级管理员（正常）
