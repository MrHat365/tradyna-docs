# 经典网格

你自己定价格上下沿和间距，系统按规则在区间内挂单、滚动补挂。

## 怎么开

1. 打开对应账户 + 品种的 DOM，等**实时行情就绪**
2. 侧栏点 **网格策略** → Tab **经典网格**
3. 填参数（可先点「按现价 ±5%」快速铺区间）
4. 看预览：层数、可活跃挂单、有没有红字
5. **保存参数** → 关掉对话框 → 点 **启动**

::: tip
启动用的是**已保存**的参数，不是对话框里还没存的脏数据。务必先存后启。
:::

## 参数白话

| 界面名称 | 白话 | 常用建议 |
| --- | --- | --- |
| 价格下限 / 上限 | 网格覆盖的价格区间 | 先用「现价 ±5%」再微调 |
| 方向 | 做多 / 中性 / 做空 | 默认中性：买卖交错 |
| 间距 | 等差 或 等比 | 新手用等差 + 固定价差 |
| 固定价差 / 等比率 | 相邻网格间距 | 价差过密层数爆炸；过稀不成网 |
| 每格数量 | 每一层下单量 | 跟保证金与风险匹配 |
| 同时挂单 | 交易所上同时挂着的入口单数量 | 默认约 50，上限 100；其余在本地排队滚动 |
| 止盈 TP | 成交后随单止盈（BPS） | 默认开，固定约 50 BPS（0.50%） |
| 止损 SL | 成交后随单止损（BPS） | 默认开，固定约 100 BPS（1%） |

**BPS**：1 BPS = 0.01%。50 BPS ≈ 相对开仓价 0.50%。

TP/SL 可以是「固定 BPS」或「范围内随机采样一次后冻结到该层」。

### 交易所注意

| 交易所 | 随单 TP/SL |
| --- | --- |
| Bitget / WEEX | 可用 |
| Binance | 可用，但保护单与入场单不是绝对同时，中间可能有短暂裸仓 |
| Gate | **必须关掉**两侧 TP/SL，否则保存/启动失败 |

## 状态怎么读

| 界面文案 | 含义 |
| --- | --- |
| 未启动 | 还没跑，或只有配置 |
| 运行中 | 会补挂、会滚动 |
| 已暂停 | **不再补新单**；已有挂单仍在所上 |
| 停止中 | 正在撤入口单；可点「重新撤单」催一下 |
| 已停止 | 入口单已处理完；随单 TP/SL **故意留下**护仓 |
| 异常 | 可尝试继续，或停止后重建 |

## 暂停 / 停止

| 动作 | 结果 |
| --- | --- |
| 暂停 | 停补挂，不撤已有入口单 |
| 继续 | 从暂停恢复 |
| 停止 | 撤本策略入口挂单；**不撤**已成交层的 TP/SL |
| 停止中卡住 | 点「重新撤单」；控制台也可再发一次停止 |

改参数：必须先停到「未启动 / 已停止」等非运行态 → 改并保存 → 再启动。

## 盯盘

侧栏看：挂单/目标、待核对、待挂、成交、最近买卖价、错误信息。

控制台 **策略监控** 也能暂停 / 继续 / 停止，并打开对应 DOM。

## 几条铁律

1. 先存后启
2. 运行中参数只读
3. 同一账户 + 品种，不能同时再开高级网格
4. 暂停 ≠ 撤单；停止 ≠ 撤 TP/SL
5. 行情未就绪不要硬启
