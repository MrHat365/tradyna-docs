# 高级网格

不手填死区间：宽度和部分风控由估计器根据行情自适应；带趋势闸门、名义敞口与回撤熔断。

## 和经典比（用户语言）

| | 经典 | 高级 |
| --- | --- | --- |
| 价格区间 | 你定上下沿 | 系统按波动自适应宽度 |
| 方向 | 你选做多/中性/做空 | 方向偏好 + 趋势过强时拒逆势开仓 |
| 启动等待 | 行情就绪即可 | 还要预热一段时间（默认约 60 根 1 分钟线） |
| DOM 上启停 | 侧栏完整 | **保存/启动**为主；暂停停止请用控制台 |
| 适合谁 | 想完全控价格带 | 接受自适应与闸门逻辑 |

同一账户 + 同一品种：**经典与高级不能同时跑**。

## 怎么开

1. DOM 侧栏 → 网格策略 → **高级网格**
2. 填参数 → **保存**
3. **启动**（若没填参考标的，界面会再确认一次）
4. 去控制台 **策略监控** 盯状态、闸门、暂停/停止

::: warning
高级网格在 DOM 侧栏的运行态灯 / 暂停停止可能不完整。请把控制台策略监控当主操作台。
:::

## 参数白话

### 基础

| 界面名称 | 白话 | 默认感 |
| --- | --- | --- |
| 每格数量 | 每层下单量 | 跟面板默认量 |
| 同时挂单 | 交易所同时挂着的单量上限 | 常见默认 20，上限 100 |
| 方向 | 做多 / 中性 / 做空偏好 | 常见默认做多 |
| 趋势敏感度 | 多大趋势力度就拒逆势开仓 | 默认约 0.25；越大越容易卡住 |
| K 线周期 | 估计器用的周期 | 固定 1 分钟 |
| 预热根数 | 开挂前要攒够多少根已收盘 K 线 | 默认 60 ≈ 约一小时（若已有历史可能更快） |

### 风险 / 宽度

| 界面名称 | 白话 |
| --- | --- |
| 宽度倍数 | 网格宽度 ≈ 倍数 × 波动估计 |
| 宽度下限 | 波动很小时的保底宽度（价格比例） |
| 资金名义 | 你愿意用的名义预算（USDT），**不是强平距离** |
| 净敞口上限倍数 | 最大净敞口 ≈ 资金名义 × 该倍数 |
| 库存倾斜 | 仓位偏了一侧时，收缩继续加仓的力度（0～1） |
| 回撤熔断 | 相对本轮峰值权益回撤超过该比例 → 拒新开 |

### 参考标的 / 空耗

| 界面名称 | 白话 |
| --- | --- |
| 参考标的 | 最多 3 个同所品种，用来确认系统性趋势；可空（需确认） |
| 空耗等待倍数 | `0` = 关；大于 0 时，久无成交且有净仓可能进入降仓退出 |

### 止盈 / 止损

与经典同套 BPS 逻辑。高级默认常：**TP 开、SL 关**。Gate 上必须两侧都关。

## 闸门状态（监控页）

策略监控里若看到闸门原因：

| 显示 | 白话 |
| --- | --- |
| 正常 / ok | 可以开新单 |
| 趋势 | 趋势闸门挡住逆势开仓 |
| 风险 / 敞口 | 净敞口触顶 |
| 偏斜 | 库存天花板 |
| 回撤 | 回撤熔断触发 |
| 风险视图不可用 | 账户投影/标记价异常 → **新开全拒** |
| 预热 | 还在攒 K 线 / 估波动 |
| 作用域互斥 | 同账户品种已有另一个网格 |

长时间卡在趋势 / 回撤 / 风险：先**暂停**，想清楚再恢复或停止重建。

## 暂停 / 停止

| 动作 | 推荐入口 | 结果 |
| --- | --- | --- |
| 暂停 | 控制台 | 不再新开；已挂单保留 |
| 恢复 | 控制台 | 继续跑 |
| 停止 | 控制台 | 撤入口单 + 降仓退出单；**保留**随单 TP/SL |
| 删除 | 控制台 | 仅已停止等终态可删 |
| 改参数 | — | 先停 → 改保存 → 再启动（运行中改草稿不会热更新） |

## 选型建议

- 要固定区间、行为可预期 → **经典**
- 要自适应宽度 + 趋势/回撤类闸门，并接受预热 → **高级**
- 不要「经典垫底再叠高级」
