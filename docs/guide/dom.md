DOM 是一扇独立交易窗：中间价格梯子，右侧侧栏。

## 布局

| 区域 | 作用 |
| --- | --- |
| 中央梯子 | 深度、成交、你的挂单投影；点价下单 / 改撤 |
| 侧栏 | 账户摘要、视图模式、下单量、预设 TP/SL、网格、快捷键 |

## 点价与挂单

1. 侧栏设好**下单量**（单位可能是「币」或「张」，跟交易所品种规则走，**不要跨所硬换算**）
2. 在梯子目标价位点击下单（买卖侧以界面为准）
3. 挂单会出现在梯子上；可改价、撤单
4. 可选：侧栏预设随单止盈 / 止损（按 BPS）；部分交易所不支持随单 TP/SL（例如 Gate 上网格会直接拒）

::: warning
仓位与挂单来自实时投影。若侧栏提示「投影中断」，先别当实盘已确认状态，等同步恢复。
:::

## 视图与居中

侧栏可切：

| 模式 | 白话 |
| --- | --- |
| 交易所档 | 按交易所原生价格档显示 |
| Tick 聚合 | 按 tick 聚合后的视角 |

梯子可自动居中，也可手动拖到你关心的价位附近。

## 仓位

侧栏 / 相关区域展示当前账户在该品种上的仓位与挂单。没有仓位时先确认：账户选对了吗？行情通了吗？

## 多窗口

- 一账户一品种一扇窗最清晰
- 可用多 DOM 启动器一次开多腿（独立窗口）
- **不要**指望用网页 iframe 嵌 DOM——产品就是独立窗

## 快捷键（可选）

默认**关闭**。在侧栏打开快捷键设置后配置，例如：

- 撤买单 / 撤卖单 / 全撤
- 买/卖盘若干档挂单
- 平多 / 平空 / 一键类平仓

实用习惯：

1. 先绑好撤单和平仓，再打开总开关
2. 输入框、对话框打开时快捷键故意失效，防误触
3. 网格启停**不是**快捷键动作——走侧栏或控制台

## 技巧速查

- 行情没深度 → 先别保存/启动网格
- 改量、改 TP/SL 预设 → 下一次新单才按新预设
- 网格与手工单会一起出现在挂单里，停止网格时**入口单**会撤，随单 TP/SL 通常保留护仓
