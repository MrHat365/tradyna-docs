# 多交易所字段对照

添加对话框里，**字段是否出现**由所选交易所决定。下表按界面实际标签写。

## 字段对照表

| 交易所（界面选项） | API Key | API Secret | Passphrase | 备注 |
| --- | --- | --- | --- | --- |
| **Bitget** | 必填 | 必填 | **必填** | 创建 API 时的口令，与 Key 成套 |
| **WEEX** | 必填 | 必填 | **必填** | 同上 |
| **Gate** | 必填 | 必填 | 无此栏 | 不要填「假 Passphrase」，框根本不会出来 |
| **Binance USD-M** | 必填 | 必填 | 无此栏 | 对应币安 U 本位合约 API |

新建时缺必填项会 Toast 拦截；Gate / Binance 即使你想填 Passphrase 也没有输入位。

## 交易所后台权限建议（用户向）

各所后台文案不统一，按意图勾：

| 意图 | 建议 |
| --- | --- |
| 读余额 / 仓位 / 挂单 | 开 |
| 合约下单、改单、撤单 | 开 |
| 现货-only、仅行情 | 通常不够，测连或交易会失败 |
| 提现 / 站内转账 / 万能 | **关** |
| IP 白名单 | 若开启，必须包含终端出口公网 IP |

::: tip
Tradyna 对浏览器**不下发**交易所 REST 下单地址；浏览器只跟终端说话。你在交易所开的仍是「给终端服务器用的」API Key。
:::

## 常见问题

### 添加时没有我想要的交易所

下拉只列本终端已启用的所。找管理员确认是否启用 Bitget / WEEX / Gate / Binance。

### 保存成功但测连失败

逐项查：

1. Key / Secret / Passphrase 是否抄混（Bitget、WEEX 最容易漏 Passphrase）
2. API 是否被交易所禁用或过期
3. 权限是否含合约交易
4. IP 白名单是否挡住终端出口
5. 是否建错产品线（例如现货 Key 拿来跑 U 本位）

### 编辑后 Passphrase 栏不见了

你在看 Gate / Binance 账户——这两家本来就没有 Passphrase。Bitget / WEEX 编辑时仍会显示，留空表示不改。

### 列表里有账户，规则页选不到

- 规则页顶部交易所页签要和账户所属交易所一致
- 该账户对你是「只读」或未授权交易时，可能进不了「可交易账户」候选
- 先在账户页确认权限列为 **可交易**，并测连成功

### 提示「账户仍有持仓或未成交订单，不能删除」

先到交易所或 DOM 里**撤光挂单、平掉仓位**，停掉引用该账户的网格，再删。不要优先强制删除。

### 提示「请先删除引用该账户的策略 / 高级网格策略」

到 **策略监控** 停止并删除相关策略记录后再删账户。

### 看不到「用户管理」

只有超级管理员有。成员账户与转移找超级管理员处理。

### 余额一直是 0 / 投影不更新

1. 测连是否成功  
2. DOM 是否用对账户打开  
3. 等私有状态同步；提示「投影中断」时先别当实盘确认  

更多症状见总册 [常见问题](/guide/faq)。
