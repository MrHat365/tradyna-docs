# 添加交易所账户

按下面做完，列表里会出现一条新账户，再去 [测连](/guide/accounts-manage#测试连接) 确认密钥可用。

## 添加前准备（交易所后台）

在对应交易所官网创建 **API Key**（名称因所而异，常见叫 API Key / API 密钥）。建议：

1. **用途**：USDT 永续 / 合约交易（Tradyna 当前接入的就是这类）
2. **权限勾选**：
   - 打开：读取账户、合约下单 / 撤单（或交易所等价的「合约交易」权限）
   - **不要**开提现、转账、万能管理类权限
3. **Passphrase**：Bitget、WEEX 创建时会让你设一串口令——**当场抄下来**，终端添加时要填；以后一般回显不了
4. **IP 白名单**（若交易所开启）：
   - 终端跑在哪台机器/哪台服务器，就白名单那台的**公网出口 IP**
   - IP 找部署该终端的管理员要；白名单漏了，测连常会直接失败
5. **只复制一次 Secret**：多数所 Secret 只展示一次，关掉窗口就没了

::: warning
API Key / Secret / Passphrase 等同于资金控制权。不要发到聊天软件、截图群、工单明文区。本手册截图一律打码。
:::

各所要填哪些框，见 [多交易所字段对照](/guide/accounts-exchanges)。

## 逐步添加

### 1. 打开添加对话框

登录 → 左侧 **账户** → 右上角 **添加账户**。

<figure>
  <img src="/screenshots/08-account-add-dialog.png" alt="添加交易账户对话框" />
  <figcaption>添加交易账户：选交易所 → 填名称与密钥 → 保存。图中密钥已打码；界面以实装为准。</figcaption>
</figure>

### 2. 选择交易所

下拉选一家（当前产品选项）：

| 界面选项 | 说明 |
| --- | --- |
| Bitget | 需 Passphrase |
| WEEX | 需 Passphrase |
| Gate | 无 Passphrase 框 |
| Binance USD-M | U 本位合约；无 Passphrase 框 |

下拉只出现**本终端已启用**的交易所。看不到某家 → 找管理员确认是否启用该所。

选中后：

- Bitget / WEEX：会出现 **Passphrase** 输入框（必填）
- Gate / Binance USD-M：不会出现 Passphrase

### 3. 填写表单

| 字段 | 必填？ | 怎么填 |
| --- | --- | --- |
| 交易所 | 是 | 见上；保存后**不能改所属交易所** |
| 账户名称 | 是 | 给你自己看的名字，如「主账户」「Bitget-合约」 |
| API Key | 是（新建） | 从交易所后台粘贴 |
| API Secret | 是（新建） | 从交易所后台粘贴 |
| Passphrase | Bitget / WEEX 必填 | 创建 API 时设的那串；Gate / Binance 无此栏 |
| 备注 | 否 | 如「合约主力」 |

缺项点保存时，界面会提示类似：`请完整填写 API Key / Secret` 或带上 `/ Passphrase`。

### 4. 保存

点 **保存账户**。成功会提示「账户已添加」，对话框关闭，列表刷新出新行。

失败时看红色/Toast 原文：常见是密钥格式不对、所不匹配、或服务端拒绝写入——把原文发给管理员即可（不要附带完整密钥）。

## 添加后立刻做的两件事

1. **测连**：同一行点插头图标（「验证 API 配置」）→ 应出现 **验证成功**。详见 [测试连接](/guide/accounts-manage#测试连接)。
2. **同步交易规则**（若该所品种列表还是空的）：左侧 **交易规则** → 选中该所 → **同步规则**。规则齐了才能在规则页选品种开 DOM。

## 一次加多家

重复「添加账户」即可。同一家交易所可以挂多个账户（例如主子账户），用「账户名称」区分。顶部统计会显示账户总数与接入交易所家数。
