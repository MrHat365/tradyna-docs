# 快速开始

管理员已经给你开好成员账户（或 Owner 访问令牌）之后，按下面四步就能上手。

## 1. 打开终端并登录

在浏览器打开你们部署的终端地址（本地常见是 `http://127.0.0.1:3000`）。

<figure>
  <img src="/screenshots/01-login.png" alt="登录页" />
  <figcaption>登录页：成员用邮箱+密码；管理员可用 Owner 访问令牌。</figcaption>
</figure>

两种登录方式：

| 你是谁 | 怎么登 |
| --- | --- |
| 交易员 / 只读成员 | 邮箱 + 密码 |
| 超级管理员 | 切到「Owner 访问令牌」，粘贴管理员给你的令牌 |

登录成功后会话写在浏览器 Cookie 里，**不用**自己存密钥。

::: tip
截图里的令牌/密码请自行打码；本手册从不收录真实凭证。
:::

## 2. 确认账户与交易规则

登录后进入主仪表盘（控制台概览）。

<figure>
  <img src="/screenshots/02-dashboard.png" alt="主仪表盘" />
  <figcaption>主仪表盘：选账户、看入口、打开 DOM。</figcaption>
</figure>

检查清单：

1. **账户**页里能看到你有权限的交易账户
2. 若列表为空，请联系管理员添加并授权
3. **交易规则**里目标交易所的品种已同步（否则可能选不到品种）

## 3. 打开第一扇 DOM

在概览或账户行点 **DOM**，或选好账户与品种后打开。窗口地址大致形如：

`/dom?symbol=BTCUSDT&account=你的账户`

<figure>
  <img src="/screenshots/03-dom-ladder.png" alt="DOM 价格梯子" />
  <figcaption>DOM 中央是价格梯子；右侧侧栏管数量、TP/SL、网格与快捷键。</figcaption>
</figure>

建议第一次只做三件事：

1. 等行情就绪（梯子有深度）
2. 设好侧栏下单量
3. 在梯子上点一档试试挂单 / 撤单（实盘前先确认你们环境允许交易）

## 4. （可选）开网格

侧栏点 **网格策略**：

| 类型 | 适合 | 下一步 |
| --- | --- | --- |
| 经典网格 | 自己定价格区间 | 见 [经典网格](/guide/classic-grid) |
| 高级网格 | 自适应宽度 + 趋势闸门 | 见 [高级网格](/guide/pro-grid) |

同一账户 + 同一品种，经典与高级**不能同时跑**。
